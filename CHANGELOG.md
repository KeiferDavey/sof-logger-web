# Changelog

## 1.0.0 — 2026-10-03

- Browser terminal for the original SoF logger Linux amd64 release.
- Web login, session expiry, logout socket revocation and WebSocket origin checks.
- Shared 140 × 40 terminal, keyboard input and control buttons.
- Pterodactyl egg, Python 3.12 installer and ncurses compatibility libraries.
- Persistent original logs, name/IP history and access settings.
- HTTPS reverse proxy and same-node container networking instructions.

Validation: local original binary startup, simulated SoF UDP replies, login and WebSocket checks. User confirmed a working connection to their SoF server using its internal container address. Full automated coverage of live kick/ban/access enforcement is not included.
